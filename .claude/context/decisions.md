# Accepted Decisions

Settled rulings that agents must not re-raise or contradict. Add an entry when a question comes up twice, or when the user rules on something that looks like a defect but is deliberate.

## Format

### [Short decision title]
**Decision**: [what was decided]
**Why**: [the reason, in one or two sentences]
**Do not**: [what an agent should not propose or flag]
**Date**: YYYY-MM-DD
